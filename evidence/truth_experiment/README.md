# Truth Experiment evidence library — intentionally not pre-filled

This folder is intentionally sparse in v0.1.

Why: a serious comparison of worldviews should not quietly rely on the model's memory or on a biased pile of sources. The engine instructs agents to treat only files in this folder as evidence and to say **insufficient evidence** when appropriate.

Before a substantive run, we should build a balanced, auditable evidence pack with clearly labeled primary sources and reputable historical/philosophical scholarship. Each item should include provenance and enough context to avoid quote-mining.

For the first software test, leaving this folder sparse is useful: it tests whether the agents obey the evidence boundary instead of bluffing.
